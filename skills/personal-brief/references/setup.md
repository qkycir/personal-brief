# 配置与验收

## 私人输入初始化

运行 `python3 <skill>/scripts/init_private.py --data-dir <private-dir>`。目标必须在仓库和Skill之外；工具拒绝覆盖已有输入。它创建运行配置、偏好、空白个人信息、空白用户确认和空账号列表，不启用来源、定时任务或网络连接。用户填写并授权后，再运行 `python3 <skill>/scripts/brief_store.py --data-dir <private-dir> init`。

每轮必须读取 config.md、preferences.md、个人信息.md 和可选 user-facts.md；范围和频率属于私人偏好，不能硬编码进通用Skill。模板在 templates/，脚本会正确填入当前安装路径。

## 能力适配

- 宿主需提供 QQ/微信可用的 Computer Use（屏幕或无障碍界面）。没有这项能力就停止对应来源，不改用客户端数据库。
- SQLite/Markdown 脚本需要 Python 3.9+，仅标准库。可手动运行，无须先配置调度。
- Apple 提醒事项使用用户已有且授权的适配器或原生界面；本包不附带第三方提醒二进制。若不可用，先输出 Markdown，不自动安装或申请新权限。
- 随附 `scripts/read_mail.py` 适用于 macOS 钥匙串 + IMAP TLS。邮箱是可选项，账号信息存在私人 mail-accounts.json；每个账号含 name/address/host/port/folders/keychain_service，不含密码。必须使用用户启用的 IMAP 客户端授权码，凭据由用户通过本机可信界面保存到钥匙串，service 与 account（邮箱地址）须匹配。不要让用户把凭据发到聊天或写进shell命令历史。
- 邮箱先用 `--check` 验证只读连接；实际读取带 `--data-dir`、`--run-id`、`--timezone`、`--lookback-days`，后两项从私人配置取得。helper 默认 UTC / 30 天不等于用户已经授权该范围。它不发送邮件，不读取附件正文；截断或过大消息保留缺口。
- 其他宿主/操作系统需自行提供并验证上述能力；不能因为理解Skill格式就宣称已兼容。

## 两阶段验收

先确认私人目录和五类来源范围（聊天、朋友圈、学校邮箱、个人邮箱、逐字稿）。凭据只在本机通过宿主安全方式设置，不写入提示词、MD 或 Git。

冷启动测试采用两个新 session：采集先执行并完成 handoff，再启动整理。增量复用测试按用户指定继续已有两个会话，保留数据库与基线，使用新的 run-id；不能清空后声称验证了增量读取。都放在用户指定项目。协调者负责读报告、修复流程及调度接口。

正式运行固定复用两个独立业务会话：采集和整理，各自保持配置指定的模型。每轮向同一采集会话投递新的 run-id，完成交接后再向同一整理会话投递；不每轮创建或归档。绑定的 thread-id 与 host-id 存在私人配置，不写死在通用技能中。不能用固定几分钟延迟替代交接检查。需要文件和桌面的本地任务，机器、App 和登录状态必须可用；锁屏/睡眠/离线记录缺口，恢复后补查。

在当前宿主中先验证独立 session 是否有 Computer Use、文件和所需连接器，以及 Apple 提醒事项写入权限。Skill 不自行安装运行时，也不绕过宿主工具限制。

最小验收：
- 新 session 仅凭配置/Skill 正确执行范围及排除名单。
- 来源消息禁止发送；未读恢复和无法恢复时的状态真实。
- 重叠采集不重复建事件；跨来源同一事项只建一项任务。
- 明确 DDL、date-only、模糊时间分别处理；历史过期不当作新紧急事项。
- 对日期与适用性明确、校区或方式未定的活动，应保留日期提醒与未知细节，不能把缺少精确截止当作缺少活动日期而整项漏掉。
- 整理者亲自回源核验后才写待办；至少用一条带旧引用的消息和一条条件式通知检验日期归属、当前条件，不以Markdown字段齐全代替事实正确。
- 用户手动完成/改期不被覆盖。
- 邮件读取不改已读、不删除/移动；凭据不进入输出。
- 提醒事项稳定 ID、到期和 alarm 经读回确认。
- 工具读回只证明保存成功；协调者还须核对verification.md与原始证据是否一致。
- 部分来源失败仍可整理其他来源，但简报保留缺口。

尚未跑通的渠道不标完成，正式自动化保持暂停或只启用已明确通过的范围。通知只走 Apple 提醒事项，禁止对外消息。

SQLite 验收还包括：写入前时间校验、事件与进度事务一致、同源事件去重、同名会话不被误合并、Markdown 可重建、个人信息输入不被导出覆盖、提醒展示有来源时间且不含内部元数据。冷测试清空派生记录前先检查用户对提醒的修改，保留用户事实和已安排通知回执。旧测试会话在取证后及时归档。
